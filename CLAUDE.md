# Task-Tracker

React + TypeScript + Vite.

## Befehle

- `npm run dev` – Dev-Server starten
- `npm run build` – Produktions-Build
- `npm test` – Tests ausführen
- `npm run lint` – Linting

## Konventionen

- Nur funktionale Komponenten und Hooks
- Keine zusätzlichen UI-Libraries
- Einfaches CSS in `src/App.css`
- Jede neue Logik bekommt einen Test

## Commits

Format: `feat: ...`, `fix: ...`, `test: ...`, `ci: ...`
